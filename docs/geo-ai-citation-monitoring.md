## 7. Evidence priority findings

Use these labels consistently:

- **SERVICE CLAIM:** A factual description of what Sky Designers offers or can include, supported by visible service copy. It is not evidence that a result occurred.
- **PORTFOLIO EVIDENCE:** A published creative, website, video, or project record that demonstrates documented output or scope. It must not be converted into a performance claim.
- **PERFORMANCE EVIDENCE:** A documented outcome with the relevant period, metric definition, data source, attribution basis, and limitations. Only the two published education Meta articles currently provide this kind of evidence.

## 10. Manual AI-citation monitoring template

### Testing procedure

1. Test manually once per month from a documented Sri Lanka context where the platform permits it.
2. Use a clean session where practical and record whether personalization, sign-in, model/mode, or experimental search features were active.
3. Run the 20 baseline queries exactly as written. Add no more than five campaign-specific queries when a new service page, article, or evidence asset launches.
4. Record the response; do not infer a citation from a mention and do not count a search-result impression as an AI answer citation.
